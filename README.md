## Stack

**Front-end**

- **언어·스타일** JavaScript · TypeScript · HTML · CSS · SCSS

- **빌드·테스트** Webpack · Babel · Vite · Jest · Playwright
- **배포·협업** AWS S3 · CloudFront · Git · Azure DevOps

**Backend · Infra**

- **런타임** Node.js
- **배포·호스팅** Vercel · Railway
- **자동화·CI** GitHub Actions

**AI**

- **개발 도구** OpenCode · Codex · ChatGPT
- **프로젝트 연동** Gemini API · Notion API · Telegram Bot

## AI로 일하는 방식

- 개발에는 OpenCode와 Codex, 조사와 의사결정에는 ChatGPT를 씁니다.
- 작업 규칙은 `AGENTS.md`에, 반복 절차는 Skills에 정리합니다. 상태와 결정은 Notion에 기록합니다.
- 내장 기능을 먼저 활용하고, 결과는 직접 실행해 검증합니다.
